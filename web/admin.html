    Correo de bienvenida

    El panel envía la clave de cada iglesia por correo. La vía que funciona en este servidor es tu cuenta de Google conectada (Gmail por HTTPS), porque el plan gratuito del servidor bloquea el correo SMTP tradicional.

    Conectar mi cuenta de Google

    Respaldo por SMTP

    Alternativa clásica: correo de envío y una contraseña de aplicación de Google (se crea en myaccount.google.com/apppasswords). Queda guardada solo en tu base de datos. Una vez guardado, los campos quedan bloqueados: para cambiarlos usa Editar, con doble confirmación. En este servidor el SMTP está bloqueado, así que este respaldo solo sirve si el servidor se mueve a un plan sin bloqueo.

    Interpretación por IA (Azure)

    La consola usa Azure Speech Translation para interpretar sin intérprete humano. Guarda la región y la clave de tu recurso de Azure AI Speech. La clave queda solo en tu base de datos: el servidor entrega a la consola un token temporal, nunca la clave. Una vez guardado, los campos quedan bloqueados: para cambiarlos usa Editar, con doble confirmación.
